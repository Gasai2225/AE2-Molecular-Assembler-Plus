# AE2 Molecular Assembler Plus

**AE2 Molecular Assembler Plus** is a Quality-of-Life addon for **Applied Energistics 2**, developed by **ChillCraft Team**, focused on late-game automation and making complex modded crafting easier to use.

The mod adds dedicated pattern terminals and molecular assemblers for supported crafting systems. It is not limited to 9x9 recipes: integrations handle large grids, custom layouts, recipe tiers, catalysts, energy costs, and specialized crafting stations.

## Features

- **Extreme Pattern Encoding Terminal** with a 9x9 crafting grid.
- **Draconic Pattern Encoding Terminal** for fusion crafting, with Wyvern, Draconic, and Chaotic Molecular Assemblers.
- **Magical Pattern Encoding Terminal** for Botania, with station-specific layouts and catalyst selection.
- Dedicated blank and encoded patterns, recipe tooltips, and AE2 autocrafting support.
- **JEI `+` recipe transfer** for supported recipe categories.
- Optional integrations: install only the crafting mods you want to use.

## New in 1.2.0: Botania Automation

Bring Botania crafting into your ME network:

- Seven specialized Botanical Assemblers: **Mana Pool, Runic Altar, Petal Apothecary, Terrestrial Agglomeration Plate, Elven Trade, Botanical Brewery, and Pure Daisy**.
- Miniature 3D station models inside green-tinted AE2-style assembler frames, with glass and powered lighting.
- Station-specific interfaces, pattern slots, progress and mana indicators, and support for up to four acceleration cards.
- Automatic station, catalyst, and reagent/container selection when transferring supported recipes from JEI.
- **ME mana storage cells from 1k to 256k**, plus mana import and export buses.
- Recipe validation prevents patterns for one station from being processed by another.
- Use an installed pattern for manual input or connect a Pattern Provider for AE2 autocrafting.

Pure Daisy currently supports item-to-item block transformations. Fluid transformations, world-function recipes, Gaia summoning, and the Mana Enchanter are not included.

## Supported Integrations

**Applied Energistics 2 is required. All crafting integrations below are optional**, including Botania, and activate only when their matching mod is installed.

- Extended Crafting
- Extended Crafting: Expanded, through compatible Extended Crafting categories
- Re:Avaritia / AvaritiaNeo, where supported by the installed fork and Minecraft version
- Draconic Evolution
- **Botania — added in 1.2.0**

JEI is optional and enables the recipe-transfer buttons. Without optional crafting mods, base AE2 recipes and the available core automation features remain usable.

Available for **Minecraft 1.20.1 / Forge** and **Minecraft 1.21.1 / NeoForge**. Use the file matching your Minecraft version and loader, and install any dependencies required by AE2 or your chosen integrations.
