# Проверка AE2 Molecular Assembler Plus — 2026-09-27

## Исправлено

- Убрана двойная регистрация MenuType: ранее MenuTypeBuilder.build добавлял меню в очередь AE2, а DeferredRegister повторно регистрировал тот же объект. В 1.21.1 используется buildUnregistered; в 1.20.1 — отдельный builder с штатным MenuOpener/NetworkHooks.
- Регистрация экранов переведена на соответствующий жизненный цикл Forge/NeoForge; удалены лишние обёртки, reflection проверки toolbar и дублирующий регистратор шаблонов.
- Ключ шаблона сохраняет NBT/components, поэтому активный план не теряет данные при сохранении.
- Передача ингредиентов сначала проверяется на копии счётчиков; отклонённый запрос не расходует входы. Учтены точные ключи и входы, распределённые между счётчиками.
- Ингредиенты расходуются до внешней выдачи результата. Удалена преждевременная выдача входов в 1.20.1. Сохраняются обычные crafting remainders.
- Extended Crafting использует собственный matcher рецептов вместо ручной копии правил.
- Рецепты 1.21.1 перенесены в data/ccapplied/recipe, обновлены result.id и neoforge:conditions. Avaritia-рецепты проверяют существование конкретных предметов.
- В 1.21.1 зарегистрирован ItemHandler для труб/воронок всех сборщиков.
- Добавлены таблицы выпадения всех сборщиков и тег mineable/pickaxe. Выпадение использует optional item tags: ресурсы корректны и без Draconic Evolution.
- Исправлен формат версии мода в NeoForge и декларация обязательных зависимостей.
- Три GUI-текстуры 1.21.1 пересобраны из элементов оригинального AE2; согласованы координаты фона, сетки, инвентаря и прогресса. Авторство и лицензия — src/main/resources/GUI-CREDITS.txt в 1.21.1.

## Проверено

Обе версии: Gradle build завершён успешно; реальный dedicated GameTest server подтвердил 7/7 тестов в Forge 1.20.1 и 6/6 в NeoForge 1.21.1:

1. Идентификаторы зарегистрированных меню.
2. Загрузка базовых рецептов и рецептов Draconic Evolution при установленном моде.
3. Сохранение и декодирование encoded pattern.
4. Отклонение неверных/лишних входов без потерь и сохранение принятого плана.
5. Доступ труб к инвентарю, запрет входа без шаблона и точная выдача результата.
6. Сборщики добываются киркой и выпадают сами.

Дополнительно для Forge 1.20.1: проверено затемнение пустых слотов без шаблона, доступность занятых слотов и активация только нужных шаблону входов. Фон сборщика расширен на 32 пикселя с сохранением исходной текстуры; сетка перенесена ниже заголовка, инвентарь выровнен.

Команды:
- Forge: gradlew.bat runGameTestServer build --offline -x downloadMCMeta --console=plain
- NeoForge: gradlew.bat runGameTestServer build --offline --console=plain

Исключение downloadMCMeta — только обход сетевого сбоя локального окружения; используется уже загруженная metadata Minecraft 1.20.1.
Обычный task test не содержит JUnit-тестов; приведённые проверки выполняются именно через runGameTestServer.

## Оставшиеся ограничения / дальнейшая проверка

- Клиент Minecraft не запускался: визуальная проверка экранов, открытие меню и анимации в реальном клиенте ещё нужны. Серверные тесты этого не проверяют.
- Не проведён полный цикл автокрафта с реальным ME CPU, отключением питания и перезагрузкой чанка.
- DraconicFusionRecipeHelper по-прежнему использует reflection и жадный подбор ингредиентов; флаги нерасходуемых fusion-ингредиентов не сохраняются в шаблоне. Такие нестандартные рецепты требуют отдельного исправления и тестов.
- Шаблоны хранят результат рецепта, но не перепроверяют его по текущему RecipeManager перед каждым крафтом. После изменения datapack возможны устаревшие результаты.
- Проверка специальных recipe-specific remainders и остатков при переполнении входных слотов не завершена. Универсальную совместимость со всеми модами эта проверка не гарантирует.
- В dev-наборе Avaritia пишет предупреждение о клиентском ItemRenderer на dedicated server; запуск и тесты завершаются успешно. Сторонний мод здесь не изменялся.

Изменения сохранены локально; push не выполнялся.
